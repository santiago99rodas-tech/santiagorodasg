## Patrones de título que se repiten

1. **"Lo que debes saber antes de viajar a ___" / "N tips / N cosas que no hacer"** (Egipto, Georgia, Marruecos).
2. **"___ en N días" + qué ver + dónde comer** (Oporto, Lisboa, Marrakech).
3. **"Cuánto cuesta ___" / presupuesto / precios reales** (Egipto, Dubái, Suiza).
4. **"Así es ___ sin filtros" / "el problema de ___"**: honestidad, encaja con la voz de Santiago.

Se usan en `../../docs/08-parrilla.md` y en `../../guiones/egipto-youtube-largo.md`. Repetir cada mes (fase 5) o antes de cada destino nuevo.
